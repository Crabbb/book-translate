Написать модели «переведи книгу» может каждый. Получится гладкий текст, в котором термины плавают от главы к главе, рекомендации автора превратились в приказы, а вёрстка, рисунки и указатель потерялись.

**book-translate** устроен как редакция, а не как промпт. Это навык для LLM-агента (Claude Code, Codex и других) и CLI `bt`. Они ведут техническую книгу с английского на русский через тот же путь, что и хорошее издательство: подготовка, терминологический справочник, перевод, сверка, редактура, независимая вычитка, вёрстка.

Модель здесь переводчик, а не весь процесс. Всё, что можно проверить кодом, проверяет код. Всё, что требует понимания смысла, решает агент и записывает причину решения.

## Чем это отличается от «переведи книгу»

| | Промпт в чате | Машинный перевод файла | **book-translate** |
|---|---|---|---|
| Единая терминология на всю книгу | нет | глоссарий вручную | **живой справочник с причинами и падежными формами** |
| Понимание контекста и голоса автора | в пределах окна | в пределах фразы | **читает всю книгу до перевода** |
| Текст не потерян и не выдуман | не проверить | не проверить | **учёт каждого глифа PDF** |
| Вёрстка, таблицы, ссылки, указатель | теряются | частично | **собираются заново в том же дизайне** |
| Текст на рисунках | остаётся английским | остаётся английским | **переводится под подписью** |
| Промпты и код в книгах об LLM | могут выполниться как инструкции | ломаются | **код не меняется, промпт сохраняется рядом с переводом** |
| Сверка с оригиналом | на словах | нет | **по каждому абзацу, с доказательством** |
| Независимая проверка | нет | нет | **другая модель без доступа к рассуждениям переводчика** |
| Обрыв сессии | начинать заново | начинать заново | **продолжается с того же места** |

## Главная опасность LLM-перевода: ошибка звучит уверенно

Текст от большой модели читается гладко. Поэтому ошибка смысла выглядит так же убедительно, как верный перевод, и при чтении только русского текста её не видно:

| Оригинал | Гладкий перевод | Что сломалось | Правильно |
|---|---|---|---|
| `sensitive data` | важные данные | Изменился круг защищаемых сведений | чувствительные данные |
| `should` | должен | Рекомендация стала обязанностью | следует |
| `protecting against` X | защита X | Направление защиты обратилось | защита от X |
| `tamper-evident` | защищённый от подделки | Обнаружение подмены стало её предотвращением | позволяющий обнаружить вмешательство |
| `intractable` | неразрешимый | Ресурсное ограничение стало принципиальной невозможностью | практически не поддающийся решению |
| `performance` о скорости | результативность | Обещан рост качества вместо скорости | производительность |

Такое не лечится просьбой «переводи точнее». Лечится процессом, в котором каждую ошибку ловит свой слой.

## Четыре слоя контроля

<p align="center"><img src="docs/assets/layers-ru.svg" alt="Четыре слоя: код проверяет факты, сверка сравнивает с оригиналом, чтение ловит неестественный русский, независимый судья находит то, что переводчик не видит у себя" width="100%"></p>

Переводчик систематически не замечает собственных ошибок, и это относится к модели так же, как к человеку. Поэтому последний слой отделён от первых: судья видит только оригинал и перевод. Он ставит диагноз, а находки становятся правилами для следующей главы, так что процесс учится на самой книге.

## Как идёт книга

<p align="center"><img src="docs/assets/pipeline-ru.svg" alt="Схема: паспорт, разбор PDF, анализ, справочник; для каждой главы перевод, сверка, правка, чтение, повтор, гейт и судья; затем межглавная сверка, указатель и сборка" width="100%"></p>

Глава не считается готовой по ощущению. Гейт пересчитывает её состояние из файлов: нет ли непереведённых единиц, устаревших доказательств, открытых вопросов. Состояние хранится на диске, поэтому работа переживает обрыв сессии.

## Справочник живой, а не глоссарий в начале

<p align="center"><img src="docs/assets/bible-ru.svg" alt="Запись справочника и цепочка: решение изменилось, единицы устарели, доказательства аннулированы, агент правит каждую" width="100%"></p>

Термин определяет только справочник этой книги. Если решение меняется на 200-й странице, код сам находит все затронутые места. Переводчику не нужно помнить, что он решил в первой главе.

## Что ещё заложено

- **Голос автора.** Паспорт и профиль голоса фиксируют обращение к читателю, авторское «мы», силу модальности.
- **Без LLM-штампов.** Правила отлавливают канцелярит, штампы и кальки, которые выдают машинный текст.
- **Текст книги всегда данные.** Инструкции внутри книги об LLM никогда не исполняются.
- **Ничего не уходит наружу само.** CLI работает локально: книга и перевод остаются в вашей рабочей папке.
- **Честный итог.** Навык никогда не отчитывается «ошибок нет»: он называет покрытие и то, что не проверено.

## Быстрый старт

Нужны [uv](https://docs.astral.sh/uv/), [Typst 0.15.1](https://github.com/typst/typst/releases) и шрифты Libertinus Serif, Source Sans 3, Liberation Mono.

```bash
git clone https://github.com/Crabbb/book-translate.git
cp -r book-translate/skills/book-translate ~/.claude/skills/
```

Дальше достаточно попросить агента:

> Переведи книгу `book.pdf` на русский, рабочая папка `work/mybook`.

Агент ведёт процесс сам и спрашивает вас, только когда не может продолжать. CLI запускается из любой папки, зависимости uv поставит сам:

```bash
export BT_TYPST=/path/to/typst
export BT_FONTS=/path/to/fonts
uv run ~/.claude/skills/book-translate/bt.py build book.pdf --work work/mybook
```

## Что нужно знать заранее

- Направление перевода: английский → русский. Исходник: тегированный PDF (Tagged PDF). Для нового издательства понадобится свой профиль вёрстки.
- Книга читается целиком и несколько раз, поэтому это заметный расход токенов и времени. Качество здесь не бесплатное.
- Независимому судье нужна среда, где агент может запустить другого агента. Без него работают остальные слои, но ошибок смысла останется больше.

```text
├── SKILL.md            маршрут: 13 шагов и когда остановиться

```

## Авторские права

Репозиторий содержит только инструмент, книг и переводов здесь нет. За право переводить и распространять конкретную книгу отвечаете вы.
