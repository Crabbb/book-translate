# Перевод книг с английского на русский

**book-translate** — навык для LLM-агента и CLI `bt` для перевода технических книг и художественной прозы. Агент сначала читает книгу и фиксирует решения по переводу. Затем ведёт главы через сверку, редактуру и приёмку. Код проверяет порядок работы и сохраняет состояние на диске, поэтому после перерыва можно продолжить с нужного шага.

## Одна схема работы, два редакторских подхода

| | Техническая литература | Художественная литература |
|---|---|---|
| Что изучает агент | Терминологию, предметные связи, голос автора, примеры и структуру книги | Персонажей, хронологию, точку зрения, голоса, обращения и повторяющиеся мотивы |
| Что сохраняет в переводе | Точность инструкций, различие между рекомендацией и требованием, единообразие терминов и смысл примеров с кодом | Характер реплик, подтекст, ритм прозы, игру слов и порядок раскрытия сюжета |
| Как принимает результат | Сверяет термины, числа, ссылки и примеры. Для тегированного PDF проверяет пересобранную вёрстку | Сверяет сцены и диалоги с оригиналом. Для художественного EPUB проверяет [девять обязательных критериев](skills/book-translate/references/fiction-epub-acceptance.md), включая цельность прозы и устройство файла |
| Пример решения | **Should** в инструкции передаётся как рекомендация, если автор не вводит требование | Смену обращения на «ты» или «вы» проверяют по отношениям героев и по всей сцене |

Если от реалии эпохи, обращения или культурной отсылки зависит смысл художественного текста, агент проверяет источники и фиксирует выбор в журнале решений. В технической книге изменение термина отмечает связанные места для повторной проверки. [Профиль художественного перевода](skills/book-translate/references/fiction.md) · [Справочник технических решений](skills/book-translate/references/bible.md)

## Обязательные этапы проверяет код

![Четыре этапа работы. Изучение книги, план и цель, перевод и редактура, сдача книги. Между этапами показаны контрольные точки](docs/assets/editorial-workflow.webp)

1. **Изучение книги.** Агент оформляет паспорт, разбирает исходник, проверяет пробную сборку на английском, читает всю книгу в заявленной области и собирает справочник.
2. **Критерии и цель.** Агент связывает критерии приёмки с конкретными фрагментами и рисками этой книги, затем создаёт и подтверждает активную цель в хосте.
3. **Перевод и редактура.** CLI выдаёт пакеты только после подготовки. Каждая глава проходит перевод, сверку с оригиналом, редактуру, чтение по-русски и повторную проверку.
4. **Приёмка.** CLI проверяет заполнение требований плана, охват и актуальность отчётов. Готовую книгу проверяют после сборки.

Если подтверждение предыдущего обязательного этапа отсутствует или устарело, `bt` блокирует следующий. `bt status` показывает ожидаемый шаг. Так можно возобновить длинную книгу даже в новой сессии. Код сверяет очерёдность, охват и хеши. Точность смысла, авторский голос и качество русского оцениваются при редакторской сверке. [Как устроена проверка переходов](skills/book-translate/references/workflow.md)

## Быстрый старт

Установите [uv](https://docs.astral.sh/uv/) и откройте репозиторий в агенте с инструментами `create_goal` и `get_goal`.

```bash
git clone https://github.com/Crabbb/book-translate.git
cd book-translate
uv sync --locked
```

> Переведи `book.epub` с английского на русский по `skills/book-translate/SKILL.md`. Используй рабочую папку `work/mybook`.

Посмотреть состояние книги с уже запущенным маршрутом:

```bash
uv run --locked bt status --work work/mybook
```

- **EPUB 3 с перетекающим текстом.** Для сборочной проверки укажите локальный EPUBCheck в `BT_EPUBCHECK`. Для пробы одной сцены используйте `workflow-start` с флагами `--pilot-chapter N --pilot-scene M`. [Как работать с EPUB](skills/book-translate/references/epub.md)
- **Тегированный PDF.** Для сборки нужны профиль вёрстки, Typst и шрифты. Пути задаются через `BT_TYPST` и `BT_FONTS`. [Как собрать PDF](skills/book-translate/references/build.md)
- **Хост и проверка.** При отсутствии инструментов цели маршрут останавливается на `goal` с сохранённой подготовкой. Для отдельной независимой вычитки нужен ещё один агент. [Независимая вычитка](skills/book-translate/references/judge-optional.md)
