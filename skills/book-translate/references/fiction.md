# Профиль художественного перевода EN→RU

В брифе укажи `passport.source.genre: fiction`. В `passport.fiction` запиши правила для `dialogue`, `inner_speech`, `written_messages` и `embedded_texts`. Эти правила попадают в пакет перевода и влияют на его актуальность. Пропусти технические проверки для отсутствующих в книге элементов, указав основание в подтверждении соответствующего шага.

Для EPUB веди записи по [критериям AC-01–AC-09](fiction-epub-acceptance.md) по ходу анализа, перевода и проверки. Они потребуются в обязательном шаге `acceptance` после `verify`.

| Шаг | Что выполнить и зафиксировать |
|---|---|
| analyze | По сценам зафиксировать точку зрения, кто говорит, что уже известно читателю, переходы во времени, мотивы и значимые повторы. Для речевых признаков указывать цитату, функцию и нарушение через `voice-set`. Привязывать локальные решения к единицам через `notes-add`. |
| bible | Записать имена, прозвища, топонимы, формы обращения и переходы «ты/вы». Различать сквозные решения и контекстные варианты. Обновлять решения через `bt`, чтобы затронутые результаты проходили проверку актуальности. |
| translate | Прочитать сцену и соседний контекст до работы над пакетом. Переводить связное окно сцены с сохранением адресов абзацев. Сохранять говорящего, точку зрения, время, недосказанность, значимое выделение и паузы. Русскую форму реплики выбирать по её функции. |
| check | Для каждой единицы сверить действие, участника, референт, порядок раскрытия сведений и смысловые акценты. Существенный дефект обосновать цитатами и конкретным изменением смысла для читателя. |
| edit и read-target | Прочитать связное окно по-русски, проверить ритм, голоса, прямую речь и ясность переходов. Зафиксировать покрытие, включая окна без правок. |
| recheck и crossbook | Сверить правки с оригиналом. По парам адресов проверить обращения, разные голоса, хронологию, возвращающиеся детали и границы знаний читателя. |

Голос рассказчика и персонажей описывай наблюдаемыми признаками. Если персонаж меняет регистр, зафиксируй, где и почему. Если в оригинале остаётся несколько правдоподобных толкований, сохрани их. Любую адаптацию, меняющую форму значимого приёма, запиши в `deviations`.
