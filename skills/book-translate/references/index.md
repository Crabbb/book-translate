# Шаг 11. Предметный указатель

Указатель пересобирается, а не переводится постранично: номера страниц в новой вёрстке другие.

1. Единицы указателя переводятся обычными пакетами: только термин, номера не трогаются. Перевод бери из справочника; подзапись не повторяет главную.
2. После перевода всей книги: `bt build <pdf> --work <папка> --draft`, затем `bt index-bind --work <папка> --positions build/book.positions.json`. Однозначное место на странице связывается само; несколько мест на одной новой странице тоже, номер всё равно один.
3. Остальное в `reports/index-open.json`: термин, вид проблемы, единицы на выбор. Реши по смыслу: `bt index-decide --file` (`[{"unit", "target", "bind", "basis"}]`). Место должно быть на той же странице оригинала, основание обязательно. Лексическое совпадение не значит «верный смысл»: проверь его и у автоматических привязок с многозначным термином.
4. Записи с одинаковым русским термином: `bt index-merge --file` (`[{"units": [...], "merge": true, "basis": "..."}]`). Разные смыслы оставляй раздельно с `merge: false`.
5. Порядок: русский алфавит, затем латиница. Буквы и номера строит сборка. Итоговая `bt build` без `--draft` не пройдёт, пока есть открытые привязки.

Записи `anomalies.jsonl` вида `index_ref_mismatch` решаются здесь: какой номер верен, определи по содержанию страниц, а не по большинству.
