# Шаг 1. Разбор книги и самотест

```text
bt ingest <book.pdf> --work <папка> [--profile <профиль>]
bt build  <book.pdf> --work <папка> --lang en --name selftest
```

**Требования.** Нужен тегированный PDF и профиль издателя в `profiles/`: соответствие стилей InDesign логическим зонам. Неизвестный стиль или нетегированный файл останавливают разбор; не обходи это, а сообщи владельцу.

**Как читать отчёт `reports/ingest.json`.**

| Поле | Норма | Если нет |
|---|---|---|
| `unmapped_glyphs` | 0 | Часть видимого текста никуда не попала. Найди страницу, поправь профиль или `ingest`, не продолжай |
| `pdfium.unexplained_pages` | 0 | Движки видят разный текст. Смотри страницу глазами |
| `open_decisions` | 0 до перевода | Текст вне дерева, который не привязался к абзацу. Реши по странице |

**Аномалии.** `anomalies.jsonl` хранит дефекты источника: неверная ссылка указателя, порченый URI, неподходящий стиль. Записи `decision: open` реши до сборки: `fix` или `keep`. Молча источник не исправляй.

**Самотест.** Сборка из реестра без перевода с проверками артефакта. Посмотри глазами рядом с оригиналом страницы разных типов: начало главы, плотный текст, код, таблица, врезка, рисунок, указатель, оглавление. Самотест ловит дефекты дешевле всего: никакого перевода ещё нет.

**Проверка глазами обязательна.** Обрезанные рисунки не видны ни одной автоматической проверке.
