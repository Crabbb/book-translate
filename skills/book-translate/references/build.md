# Шаг 12. Сборка

```text
bt build <book.pdf> --work <папка> --lang ru
```

Нужны `BT_TYPST` (путь к Typst 0.15.1) и `BT_FONTS` (каталог со шрифтами Libertinus Serif, Source Sans 3, Liberation Mono).

Проверки артефакта обязательны: единица присутствует один раз; нет обрезания и наложений; встроены только ожидаемые шрифты; код совпадает с каноном; ссылки ведут на верные цели. Они ловят не всё, поэтому **просмотр глазами обязателен**.

Выборка: начало главы, плотный текст, код, длинная таблица, врезка, рисунок с текстом, указатель, оглавление, пустая страница, плюс все страницы с аномалиями. Сравни рядом с оригиналом.

Итоговый отчёт содержит: покрытие, `provisional`, отклонения, аномалии с решениями, полноту проверки при калибровке, непроверенное. Формула «ошибок нет» запрещена.
