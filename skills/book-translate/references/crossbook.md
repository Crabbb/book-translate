# Шаг 10. Межглавная сверка

Читай карты и сверяй пары мест, а не всю книгу заново. Находка цитирует **оба** места или источник. Предположение без второго места находкой не считается.

| Сторона А | С чем сверить | Вопрос |
|---|---|---|
| Заголовок главы | Её содержание | Обещанное действительно есть? |
| Резюме и выводы | Текст раздела | Совпадают утверждения? |
| Концепт | Проза, таблицы, подписи, код | Один термин держит один смысл? |
| Код | Его пояснение | Идентификаторы и шаги те же? |
| Рисунок и его текст | Проза рядом | Говорят об одном? |
| Номера рисунков, таблиц, отсылки | Сами объекты | Ведут туда, куда написано? |
| Оглавление | Заголовки | Совпадают дословно? |
| Сквозной пример | Все его появления | Те же имена и числа? |
| Обращение и голос | По главам | Нет дрейфа? |

Коды `T6` (один концепт, разные передачи) и `T7` (два концепта, одна русская форма) из `bt qa` без `--pages` дают отправную карту.

Найденное: обнови справочник и исправь единицы; `bt status` покажет устаревшее. Сборка запрещена, пока stale не равен нулю.
